FAQ

Pertanyaan yang sering diajukan

Apakah APK hasilnya benar-benar bisa dipasang?
Ya. APK dibangun dengan Android SDK + Gradle dari proyek WebView asli dan ditandatangani dengan debug key, sehingga dapat dipasang di Android (aktifkan “Instal dari sumber tidak dikenal” pada pengaturan perangkat). Untuk distribusi publik atau Play Store, gunakan signing key produksi seperti dijelaskan di README.
Bagaimana keamanan file yang saya unggah?
Backend membatasi ukuran file, memeriksa tipe file, menolak ZIP dengan path traversal, entri terenkripsi, atau total data yang tidak wajar (proteksi zip bomb). File hanya dipakai untuk membangun APK Anda. Token GitHub hanya dibaca di server dan tidak pernah dikirim ke browser.
Berapa lama proses build berlangsung?
Umumnya 2–5 menit, tergantung panjang antrean runner GitHub Actions dan ukuran aset website Anda. Halaman status memperbarui dirinya otomatis sampai build benar-benar selesai.
Mengapa build saya gagal?
Penyebab paling umum: ZIP tidak memiliki index.html di akar paket, file rusak, atau aset terlalu besar. Buka tautan “Lihat log build di GitHub” pada panel status untuk melihat log kompilasi yang sebenarnya.
Apakah saya perlu akun GitHub?
Tidak. Admin server yang menyiapkan repository dan token GitHub sekali saja. Pengguna cukup mengunggah file, mengisi nama aplikasi, dan mengunduh hasilnya.
Status menampilkan “build belum dikonfigurasi”, apa artinya?
Server belum memiliki kredensial build. Admin perlu mengisi variabel lingkungan GITHUB_TOKEN, GITHUB_OWNER, dan GITHUB_REPO (lihat README). Sistem sengaja tidak menampilkan status berhasil palsu saat kredensial belum ada.
Apakah website saya butuh koneksi internet?
Aset yang Anda unggah dibundel di dalam APK sehingga dapat dibuka tanpa internet. Halaman yang memuat resource dari domain eksternal tetap membutuhkan koneksi, dan izin INTERNET sudah disertakan.
